
Lean software development


https://en.wikipedia.org/wiki/Lean_software_development


Lean software development is a translation of lean manufacturing principles and practices to the software development domain.

This Agile methodology is iterative, just like Scrum, and focuses on delivering fully functional batches. The methodology is highly flexible and does not have any rigid rules or guidelines.

Its main idea is to eliminate what is called waste. This is done by letting users of the system select only the precious features for the system. These features are then prioritized and delivered in small batches.

It relies on rapid and reliable feedback from the users of the software. In Lean
development, the work is pulled by customer requests.



Lean development can be summarized by seven principles, very close in concept to lean manufacturing principles:

    Eliminate waste
    Amplify learning
    Decide as late as possible
    Deliver as fast as possible
    Empower the team
    Build integrity in
    Optimize the whole



Lean Software Development Phases

Lean Software Development is based on the Lean principles originally developed for manufacturing. It focuses on optimizing the flow of work, eliminating waste, and improving efficiency.
a. Eliminate Waste

    Objective: Identify and eliminate unnecessary activities or tasks that don't add value.
    Key Activities: Streamline the development process and avoid overproduction, waiting, and other wasteful practices.

b. Build Quality In

    Objective: Emphasize building software that is of high quality from the start.
    Key Activities: Implement quality practices such as automated testing, pair programming, and code reviews.

c. Create Knowledge

    Objective: Continuously improve processes and adapt based on lessons learned.
    Key Activities: Encourage learning at every stage through feedback loops and retrospectives.

d. Deliver Fast

    Objective: Release working software frequently to obtain feedback early and make improvements.
    Key Activities: Use continuous delivery to deploy small, incremental changes quickly.
