character entity represents a character that's special

for example  a less than symbol in the middle of our text would confuse the browser, as it would parse it as the beginning of a tag.

To display a less than sign you use the character entity, ampersand lt semicolon.

character entities start with the ampersand, and end with a semicolon.

Special Characters
&lt;        \< - Less-Than Symbol
&gt;        \> - Greater-Than Symbol
&amp;        & - Ampersand, or 'and' sign
&quot;        " - Quotation Mark
&copy;        © - Copyright Symbol
&trade;        ™ - Trademark Symbol
&nbsp;        - A space (non-breaking space)
&#??;        ISO 8859-1 character - replace ?? with the iso code
