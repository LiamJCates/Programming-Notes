C++ declaration statements, or declarations, introduce identifiers into a scope.

A declaration is a statement that introduces an entity into the program. 

In C++, identifiers can only be used in expressions once they have been declared. For example, some variable x cannot be used before being declared with a statement, such as:

  int x;

The compiler reads files from top to bottom, so a declaration must appear before its point of first use.

It specifies a type for the entity
[see type]

• A type defines a set of possible values and a set of operations (for an object).
• An object is some memory that holds a value of some type.
• A value is a set of bits interpreted according to a type.
• A variable is a named object
