When you compile a C++ program, the compiler is responsible for making sure your program follows the syntax rules of the language.
Violation of syntax rules results in an error during compilation.
A syntax error is a compiler error that occurs at compile-time when your program violates the grammar rules of the C++ language.


The text of a C++ program is built from characters consisting of a standardized set, and consists of 
    tokens
    comments
    white space 

A token is the smallest element of a C++ program that is meaningful to the compiler.

Whitespace refers to characters that are used for formatting purposes and are only significant in that they separate tokens.

Comments, while composed of characters combinations that may otherwise be recognized as tokens, are for developer use only and are disregarded during compilation.
