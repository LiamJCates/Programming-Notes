Stands for 'Not-A-Number'.

It represents a computational error. When the JavaScript engine cannot compute a result, it returns 'NaN'. 

For example:

     ```javascript
     "Hello" + 1; // Returns "Hello1"
     "Hello" - 1; // Returns NaN
     ```

     In the first case, the engine concatenates the string with the number. In the second case, since subtracting 1 from "Hello" is not a valid operation, it returns NaN.
