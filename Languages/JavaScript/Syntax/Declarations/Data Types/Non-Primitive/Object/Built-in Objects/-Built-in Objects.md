## 5. Built-in Objects in JavaScript

JavaScript offers a range of built-in objects that you will frequently interact with, including:

- **Object:** The base object for all objects.
- **Array:** For handling ordered collections.
- **Date:** For working with dates and times.
- **Math:** For mathematical constants and functions.
- **String, Number, Boolean:** For working with primitive data types wrapped as objects.
- **RegExp:** For pattern matching and regular expressions.

### Example of Using a Built-in Object (Array):

```js
const numbers = [1, 2, 3, 4, 5];
const doubled = numbers.map(num => num * 2);
console.log(doubled);  // Output: [2, 4, 6, 8, 10]
```
