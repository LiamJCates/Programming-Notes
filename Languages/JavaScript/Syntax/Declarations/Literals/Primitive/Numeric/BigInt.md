BigInt is a numeric data type that can represent integers in the arbitrary precision format, used to represent integers that are larger than the Number data type can handle.

To denote a BigInt, suffix the number with an 'n'. For example, `10` is of type Number, while `10n` is of type BigInt.

BigInt literals can be written in decimal (base 10), hexadecimal (base 16), octal (base 8) and binary (base 2).
