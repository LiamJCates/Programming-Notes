In computer science, arbitrary-precision arithmetic indicates that calculations are performed on numbers whose digits of precision are potentially limited only by the available memory of the host system. This contrasts with the faster fixed-precision arithmetic found in most arithmetic logic unit (ALU) hardware, which typically offers between 8 and 64 bits of precision.

Rather than storing values as a fixed number of bits related to the size of the processor register, these implementations typically use variable-length arrays of digits.
Arbitrary precision is used in applications where the speed of arithmetic is not a limiting factor, or where precise results with very large numbers are required.

Several modern programming languages have built-in support for bignums and others have libraries available for arbitrary-precision integer and floating-point math. 
Also called bignum arithmetic, multiple-precision arithmetic, or sometimes infinite-precision arithmetic.
